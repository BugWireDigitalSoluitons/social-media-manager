# Social Media Manager

Private-first, tenant-aware social analytics for a contemporary romance author, with a conventional dashboard and a separate read-only agent interface.

Status: architecture and project memory initialized; application, integrations, migrations, and security automation are not implemented yet.

The primary project memory is the Obsidian vault at [Docs/SocialMediaManager/Home.md](Docs/SocialMediaManager/Home.md).

Initial outcome: sign in, create a workspace, connect authorized Facebook/Instagram accounts, trigger a scan, inspect saved observations and collection health, and verify scheduled scans. Posting and content generation are outside the initial scope.
